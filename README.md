# 🧮 Matrix Calculator Web Service

## 📘 Overview

This project implements a **SOAP-based web service** for matrix operations (**addition**, **subtraction**, **multiplication**, **transpose**, **determinant**) using **JAX-WS** and **JDK 21**.  
The service is published programmatically using `javax.xml.ws.Endpoint`.
